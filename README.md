# drizzo.uk

Personal website built with React and Vite.

```sh
npm ci
npm run dev
```

Edit `src/data.js` for projects and experience, `src/main.jsx` for the page,
and `src/styles.css` for styling.

`npm run build` builds to `dist`. Pushes to `main` deploy through GitHub Pages.
The `design-reference` branch keeps an earlier layout and is not deployed.
